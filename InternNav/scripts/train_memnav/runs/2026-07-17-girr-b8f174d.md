# GIRR long-range revisit calibration run

## Hypothesis

The dominant failure is not generic LingBot turn-pose loss. On the locally cached
full-stream diagnostic, short two-leg relative bearings remain accurate while
three-leg/long-gap bearings degrade sharply. A raw metric pose token therefore
injects unreliable long-range geometry into the action decoder even when semantic
retrieval is correct.

This run evaluates Gauge-Invariant Reliability-Calibrated Revisit (GIRR):

- encode the corrected NavDP ground-plane bearing and a stream-scale-normalized
  range, without raw translation or full endpoint rotation in the action token;
- keep semantic revisit probability separate from pose reliability;
- train pose reliability against clipped cosine agreement with the GT bearing;
- condition diffusion with `semantic_gate * pose_reliability`;
- log calibration and long-gap diagnostics, including reliability target, Brier
  error, raw bearing error, scale drift, anchor gap, and path span.

The reliability target is training-only. Inference uses only LingBot trajectory
consistency, temporal gap, pose geometry, and semantic-score statistics.
