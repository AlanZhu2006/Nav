# MemNav official sparse-keyframe training run

## Purpose

This run tests the production version of the locally validated long-stream fix:

- LingBot's official `ceil(num_frames / 320)` post-scale keyframe policy;
- dense per-frame DINO/pose outputs but sparse aggregator and camera KV memory;
- raw camera RoPE indices preserved across sparse KV injection;
- global sparse memory plus 64-frame local dense goal warm-up;
- pose reliability retained as a diagnostic but removed from conditioning and loss by default;
- fail-closed cache schema/signature and deployment dependency checks.

The 400-step result must be compared with the old `b8f174d` run using fixed held-out metrics. A
successful task is not, by itself, evidence that navigation quality improved.
