# Retrieval-aware range and live-anchor training run

## Question and controlled comparison

This run tests whether the small local gain from range supervision plus live retrieval-anchor
exposure survives a full 400-step training run. It is a controlled candidate experiment, not a
production-default change and not a closed-loop Habitat result.

The comparison baseline is `mkf-train-1371557-400` (JobID `14124336`, W&B run
`memnav_mkf_1371557_400`). Both runs use the same sparse caches, split seed, random-leg sampler,
batch size, 400-step bound, fixed 64-sample validation population, and evaluation interval. The
treatment changes only:

- `MEMNAV_W_AUX_RANGE`: `0.0 -> 0.2` with SmoothL1 beta `0.1`;
- anchor teacher forcing: constant `1.0` becomes `1.0 -> 0.5` over 400 steps.

The anchor mask uses its own step-derived generator and does not perturb diffusion's global RNG.
Evaluation always uses the live retrieval anchor. Direction and range losses are masked when a live
anchor is a known negative, while the action objective still sees that example.

The local 20-step result was only a `0.216%` revisit full-DDPM MSE gain. That is too small to claim
generalization; this longer run is required before changing defaults.
