# 联合定位的点顺序归因控制

补充于几何提取期间、任何真实 query 求解之前；不修改原三臂和 frozen manifest。

联合输入去重后按 query 像素坐标排序。RANSAC 在固定种子下也可能因对应点顺序
改变而产生不同采样。不能将这个随机采样差异误称为“多视图信息收益”。

因此独立 verifier 额外执行一个纯 CPU 控制：每张单帧的原 2D–3D 对应同样按
query (x,y) 排序，用完全相同的 solver/config/query intrinsic 重算。
记录几何第一帧的排序控制，以及这八个排序控制中真实位置误差最小的离线 oracle。
该控制不改变原方法的输入/输出，不是新的部署臂，不选择最佳 RANSAC seed。

只有联合相对原单帧和点顺序控制均存在改善，才将其作为额外信息可能有用的证据。
求解后若发现其他混淆，必须报告，不能通过改参数替换本轮主结果。
