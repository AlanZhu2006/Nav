# GEM 固定 top-8 多参考定位：本机开发协议

本轮只测试定位信息，不运行导航、不训练模型、不改变主方法或论文结果。

## 问题与人口

当前 geometry-first 路径从同一 top-8 中选一帧做 PnP。本实验比较：

1. 原几何排序第一帧的 PnP；另外记录原证书是否接受。
2. 八个单帧 PnP 中真实平面位置误差最小者：仅评分端 oracle，不可部署。
3. 同一八帧的去重 2D–3D 对应联合 PnP：没有新的授权规则，不输出控制。

使用本机 train40 候选表和已经搬回的因果 RGB 前缀。按 scene/history 字典序，
选前八个各自拥有至少四个完整 session、所需历史帧不超过 384 的不同场景；
每场景只取第一个满足条件的 history，纳入其全部合格 session。
资格只依据输入完整性、历史长度、候选在 decision 之前；不依据共视、旧成功或新误差。
缺任一候选时排除整个 session，不把 top-8 缩成可用子集。

这批历史来自专家轨迹训练资产，不是 online NavDP-A。多个 session 可能复用目标图；
同时报告 session、独立 query hash、history、scene 数，不能把它称为导航 SR。

## 固定的求解

- 重用原 DINO top-8，不扩 K、不重新检索、不读取 role/covis 选择候选。
- 冻结 SuperPoint/LightGlue；以原 native-pixel Fundamental-MAGSAC 统计排序。
- 2D–3D 对应使用原 pad-pixel Fundamental-MAGSAC 过滤、正的有效 LingBot 深度。
- 所有候选使用同一查询内参：本 session 几何排名第一帧的预测内参。
  这与主路径第一帧的默认内参一致，也避免联合臂多出相机标定改变。
- 同一个 SuperPoint query 关键点跨参考重复时，只保留 LightGlue score 最高的
  一个对应（同分按 anchor/原匹配顺序），不是累计独立内点、不是平均多个错误 3D 点。
- 单帧与联合都使用既有 SiftPnPConfig：EPNP-RANSAC + LM，种子与迭代数不变。
- 主路径的单帧证书照常记录，但联合臂不冒用其 reference-hull/accept 语义。
  全部 pose 输出是诊断，不获得控制或停车权限。

## 几何与评价边界

补提取选定历史中所需 anchor 的完整深度/置信度，不读取目标图或 GT 参与流式建图。
历史 pose 与相机高度尺度使用已有绑定的 train40 资产；这里是 first64 height receipt，
不是生产 first40。深度提取配置与已有 train40 几何提取一致。
八个候选在同一历史坐标系中提升为 3D 点，不另用 GT 对齐各帧。

评分另行读取监督 parquet/meta。共同评价坐标是几何排名第一的历史相机：
比较该相机到目标的平面相对位移，尺度仅来自原高度收据。这样不把 GT 用作建图对齐。
报告的是 **anchor-relative** 位置/直线方向误差，不是决策时刻的当前 bearing，
也不是测地线首段方向误差。很多本地前缀未覆盖真正 decision 时刻，不伪造当前 pose。

主要指标：全体 session 的有效输出、平面误差 <=0.5 m、输出位置误差分布；
方向误差仅在真实 anchor–goal 平面距离 >=0.5 m 时统计，近零位移不适合角度评价。
按 top-8 原共视标签报告 <=0.1 / (0.1,0.5) / >=0.5，不将其等同真实全历史 Novel/Revisit。
报告共同有限输出上的配对差异，以及所有 session 的改善/退化，保留无输出。

每个 session 保存八个单帧结果、联合结果、去重前后点数、参考贡献与求解时间。
离线 oracle 只按同一位置误差选一个输出，方向指标也用这个输出，不另挑角度最佳者。

## 实施与停止条件

先合成几何单元测试，再冻结本地 manifest、提取所需几何、运行定位、独立复算。
新增数据/代码单独保存；不覆盖旧实验，不修改正在运行的真机服务。
本轮结束必须给出数值或明确的输入/运行失败原因；不以“已准备”冒充测试完成。
若联合没有稳定收益，不延长训练或自动上 HPC。即使改善，也仅是开发定位结果，
需要包含原成功、失败和无支持查询的闭环测试后才能讨论主方法升级。
