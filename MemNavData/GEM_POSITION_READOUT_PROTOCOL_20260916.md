# Matched-support position-readout diagnostic, 2026-09-16

Use all seven existing main-table queries with an accepted legacy GEM recall and at least 1 m planar distance between the selected support camera and the target camera. Membership is frozen from the earlier geometry audit. This is a post-hoc, accepted-recall diagnostic of position readout, not a fresh benchmark or an independent success-rate confirmation. It differs from the previous offline historical-position comparison, which used oracle historical poses.

Two arms share each original history, goal, initial state, seed, A100 GPU, legacy/window32 geometry, canonical reference depth, DINO shortlist, SP/LightGlue/PnP, strict certificate, original ImageGoal and frozen NavDP interface. The PnP-goal arm consumes the original predicted goal bearing. The historical-camera arm changes only the accepted current-relative direction to point toward the predicted pose of the same selected support camera. It keeps the original certificate and cached PnP estimate intact. Neither arm receives ground-truth positions or goal/support offset through the model boundary. No alternate anchor is selected and no gate is forced.

Both arms execute with a 600-action budget and a shared 0.3 m automatic arrival threshold. All explicit turn actions count toward the budget. Independently record first passage at Euclidean and geodesic radii of 1.0, 0.5 and 0.3 m, endpoint error, minimum error, actions, turn actions and recorded bearing error. Entering 1 m does not terminate these new runs. These measurements do not test autonomous STOP. The old 1 m-stopped trajectories are not relabeled as tighter-threshold trials.

Validation reconstructs actions and path length using the same execution audit, now explicitly parameterized by the success radius with its original 1 m default preserved. Check identical initial RGB, depth, geometry, shortlist, selected support, certificate and PnP across arms. Recompute the historical-camera bearing from the recorded predicted camera poses and verify the actual consumed direction. Ground truth is used only in offline metrics. Retain valid failures and report any query on which the certificate abstains in both arms.

The first pair is the longest history among these seven and remains part of the 14-rollout total. Launch the remaining six pairs only after complete execution validation of the first pair. Record all seven paired outcomes; treat aggregate differences as descriptive at this sample size. Do not tune the memory, gate, controller, stopping radius or sample membership after observing results.
