# HM3D 共视 0.1–1.0 分层：冻结协议

日期：2026-09-09。状态：构造与实验设计；尚无本实验 SR。

## 1. 目的和与旧实验的区别

固定方法，改变目标图在历史中的可观测支持，检验 memory 的收益随支持程度如何变化，
并将已修复的 RGB、深度栅格、转身和有界执行接口用于完整查询评测。
不是调整 certificate 阈值，也不是用 DINO 分数代替共视。

旧 Final14 已有弱/强支持实验，但实际弱档集中于 0.399–0.406、强档为
0.615–0.721，且执行版本较旧。本实验补的是完整范围和受控比较，不声称首次测支持。

## 2. 冻结来源与结论范围

- 使用 HM3D Table-I fresh-query reserve 的全部 28 条真实单目 online-A 历史、21 scenes。
- 来源 manifest SHA256：`f82dbcbc6255219aae94b6d77bffdfa454f36835cf803a70df5cf8616193ad01`。
- 不重采 A，不用 expert 轨迹替换真实历史，不按旧 SR 挑历史。
- A 来自旧冻结执行版本；本实验是**固定真实历史后的、修复接口下的查询阶段消融**，
  不能替代“重新用修复系统执行 A”的端到端结果，也不称独立 fresh confirmation。
- 全部模型、检索规则、认证阈值及 2.5 m residual 固定；不读取此实验结果调参。

## 3. 操作性共视定义

对目标图 G 中有效深度像素对应的表面点，计算它们投影进历史帧、未越出视野，且
投影深度与渲染深度相差不超过 0.30 m 的比例。逐帧得到 c(G,H_i)。
本实验主分档量为 `q = max_{39 <= i < N_A} c(G,H_i)`，即几何记忆可用的历史支持。
它是**目标到历史的单向覆盖比例**，不是 IoU，也不是整个历史的平均值。

- 同时保存全部历史（含前 39 帧）的最大值、完整逐帧曲线，避免混淆支持与寻址失败。
- 不用 DINO top-1/top-8 限定构造分母；检索命中率和被选 anchor 的共视属于结果。
- GT pose/depth/NavMesh 仅用于构造、注释和评测；不送入策略或记忆服务器。
- 标注使用实际 Habitat 投影矩阵内参、原始浮点深度；不使用截断到 6.5535 m 的 PNG
  深度计算支持。历史 RGB 仍是原始在线记录，不是新合成的控制历史。
- 目标像素步长 6，有效深度范围 (0.15,10) m，历史逐帧计算，不抽掉困难帧。
- 分组在查询前冻结，不用查询过程中新增画面的支持重新分组。

## 4. 五档与配对构造

| 档 | 主实验共视区间 |
|---|---|
| 1 | [0.10, 0.30) |
| 2 | [0.30, 0.50) |
| 3 | [0.50, 0.70) |
| 4 | [0.70, 0.90) |
| 5 | [0.90, 1.00] |

区间左闭右开，最后一档包含 1；最后一档宽度较小，不比较未归一化候选数量。

同一历史的所有档固定：完整历史、A 终点/起始朝向、目标物理位置、相机高度、视场角、
目标距离、预算和随机种子。目标位置沿用已冻结 standard Revisit；仅改变目标相机 yaw。
按原 yaw 加 0,5,...,355 度穷举 72 个方向，禁止根据控制表现增加搜索。
各档从全部合法候选中用 `SHA256(seed/history/bin/yaw_index)` 排序取第一项，
不按接近区间中点选择，防止再次把一个宽区间做成几乎单个取值。

目标始终独立重渲染，不能复制历史 JPEG；若 JPEG 与任一历史帧完全相同，该候选不入选。
不移动位置来凑高档，不改变阈值，不对图像人为遮挡，不删除历史。
朝向变化也会影响 native 的 ImageGoal 难度，因此每个目标必须有独立配对 native；
不能将 across-bin SR 差异解释成与朝向无关的纯标量共视因果效应。

另保留原始 Natural Novel 查询作为单独对照，不计入上述五档，也不混入总体平均。
旋转后低支持的 Revisit 地点不自动称为 Novel 地点。原 Novel 的新标注值照实报告，
即使因标注内参/浮点深度校正而超过旧阈值，也不静默换目标或改标签。

## 5. 样本与缺失格

设计上限：28 histories × 5 档 × 3 arms = 420 次主实验 rollout，
另有最多 28 × 3 = 84 次原 Natural Novel 对照。**上限不是保证可构造的样本数。**

先构造整个冻结总体，再封存每个目标及全部空格原因，然后启动查询评测。
只由构造决定的空格不算导航失败；已选目标上的导航失败必须保留。
输出各档 histories/scenes、真实 min/median/max、分布、目标距离和朝向分布。
报告所有可用格的三臂配对结果；跨档趋势另报告五档共同历史子集，并注明选择范围。
共同子集若过小仍报告实际规模，不以事后补样或改边界掩盖。

## 6. 三臂和执行接口

1. `native`：单目 native NavDP，无 memory 接管。
2. `raw_fixed`：冻结 raw-DINO fixed-bearing 路线，无完整几何认证。
3. `cec`：冻结几何认证 + unit bearing × 2.5 m；拒绝按既有契约执行 native。

运行栈继承 `repaired_fullmono_c8cf8c60e7efd55f`，不从脏工作区重新打包模型。
使用 repaired RGB/source-depth raster、物理朝向对齐、有界轨迹追踪和环境碰撞响应；
不使用旧候选落点 snap + 缩短再试的规划辅助，不打开 oracle bearing、graph rescue 或 GT odometry。
环境碰撞仍使用 Habitat NavMesh，不能表述为“仿真完全不使用 NavMesh”。

每个 history × query 的三臂在同一个 A100 array element 顺序执行，重置后重放完全相同的
历史；同一模型进程服务三臂。六种 arm 排列按固定任务索引轮换，固定随机种子。
预算：600 ticks、每次执行 8 ticks、成功距离 1.0 m，沿用原 stopped/stuck 条件；
这是 evaluator 到达判定，不是已验证的自主视觉 STOP。

## 7. 指标与分析（结果前固定）

主指标：逐档 SR、精确 SPL；同时给出各方法路径长度、ticks、总转角和耗时。
SPL 使用实际逐动作位移及末动作后的终点，不能沿用名义速度积分。

主比较：各档 CEC−native 的配对风险差；并列报告 CEC−raw。
每项列 N、scenes、gain/loss、exact McNemar p、scene-cluster bootstrap 95% CI。
五档组成各自预定义的比较族，报告原始 p 和 Holm 校正 p，不挑一档显著值写总声明。
scene 为重采样单元，保留同场景历史和三臂配对；五档不是独立实验重复。
完整分层平均只能叫所构造 spectrum 的 macro average，不能当自然环境部署 SR。

机制指标：query-first 和 ever 的检索/证书接管情况、top-1/top-8 与完整历史支持的差距、
PnP 成败及拒绝原因、被选 anchor 的共视、bearing 相对真实目标直线方向的误差。
若额外比较测地线路线首段方向，必须单列命名，不混为定位误差。
不把“仅认证成功子集 SR”作为主方法 SR。

## 8. 执行安排与边界

按共享 SSH 手册复用 `alantorch`/`yz11502`，A100、每任务 1 h、并发最多 4。
构造阶段只加载 Habitat，不启动 LingBot/NavDP，不产生 SR；不安装或更新环境。
构造输出封存后才发布实际 query task manifest。
正式 rollout 的大批逐帧收据应写节点临时目录后按完整任务打包保留，避免 scratch
文件数量配额耗尽；不能删除原实验补空间，也不能因打包丢掉精确 SPL 终点。
