The original Natural-V4 protocol required at least 40 supported histories and
therefore correctly halted after factual B.  The independently verified sealed

This amendment does not pretend that the original power gate was met.  It
authorizes a separately labelled, underpowered mechanism test on every sealed
history and permanently withholds the powered-confirmation claim.

The causal comparison is:

```text
sealed actual-mono A -> sealed actual-mono B -> one factual C
```

Thus B2 asks whether a previously Novel B becomes useful episodic memory after
the agent has actually experienced it.  The two treatment arms run on the same
GPU and process with balanced order.  A forced-reject native arm records the
same shadow proof without granting control.  Runtime role labels, simulator
metric depth, threshold tuning, population replacement, and post-B2 filtering
remain forbidden.

All 22 factual-C rollouts are executed exactly once.  Every successful C is
sealed before any B2 arm runs; failures remain in the attrition ledger.  B2 is
then evaluated from the exact same C RGB/pose/action prefix.  The report must
include causal denominators, paired gain/loss, exact McNemar, scene-cluster
bootstrap confidence intervals, and factual-B anchor provenance.

C2 is deliberately excluded from this amendment.  Once B2 arms diverge they no
longer share a C2 start state, so C2 would not isolate the accumulation effect.
Existing longer-sequence experiments may be reported separately as secondary
lifelong evidence, but they cannot be merged into this paired B2 estimand.

Regardless of the numerical result, this run is described as an underpowered
external continual-memory mechanism test, not as the original powered HM3D
confirmation and not as fresh-scene generalization.
