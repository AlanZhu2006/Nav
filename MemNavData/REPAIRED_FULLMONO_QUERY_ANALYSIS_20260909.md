# 新实际 mono-A 三臂：结果汇总口径

2026-09-09，在新的 query population 封存/导航前固定。
本文件只补汇总入口，不改变已提交 A/构造的代码、样本或运行方法。

`summarize_repaired_fullmono_queries.py` 复用现有 `group_stats`：

- Novel、Revisit、等比例合计三种分母同时报告，不择取其中最好的一种。
- 每臂给到达数、SR、实际位移 SPL、路径、动作数、转角及运行耗时。
- GEM 对 native、GEM 对 raw 同时给 gain/loss、配对风险差、exact McNemar，
  以及 20,000 次 scene-cluster bootstrap（seed 20260909）的95%区间。
- 分角色列出 GEM 接管查询数、无接管且逐动作等同 native 的查询数。
  这不是 Novel/Revisit 二分类准确率，也不是安全保证。
- A 的所有源、到达数和构造损耗另列。条件 query SR 不被写成源任务 joint SR；
  等比例构造也不能代表自然任务流的真实角色比例。
- 未完成的配对或归档只输出缺失清单，不产出终局 SR，也不把故障当导航失败。

每个 task 必须是完整三臂，源版本、总体、角色、顺序及归档核验一致。
汇总依赖每任务已有的逐动作/末步独立 verifier；它不是再次运行导航。
读取全部原始归档 SHA，复用已有 source/构造收据读入，不补造缺失观测。

五项新合成单元测试覆盖分母、未完成任务、错误总体和归档变化；测试数据不是真实实验。
与已有构造/封存测试合计15项通过。
