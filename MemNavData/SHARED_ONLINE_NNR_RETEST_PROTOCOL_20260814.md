# Actual-online Novel → Novel → Revisit strict retest

Date: 2026-08-14

## Why this rerun exists

The external qw2440 strict-v4 run reported:

- native `SR_C | A,B = 4/22 = 18.2%`;
- known-role direct `14/22 = 63.6%`;
- role-free certified `10/23 = 43.5%`.

The certified denominator differed from native (`23` versus `22`), so the
three values are not a paired method comparison.  More importantly, strict-v4
Goal-C was defined from the generator's expert A trajectory, not necessarily
from frames observed by an online NavDP A rollout.  The old result remains a
useful external diagnostic, but it is not the requested actual-online causal
test.

## Frozen population and benchmark construction

Source data are qw2440's 100 episodes generated by
`multileg_v4_role_paired_20260812`.  No goal or outcome from development or
blind scenes is read.

1. Select the 22 source-native episodes in which both A and Novel-B succeeded.
2. Freeze the factual native A and B RGB/pose streams.  The source controller
   had no MemNav observer; replay into MemNav is explicitly observation-only
   and cannot alter A/B control.
3. Construct Goal-C only from a factual online-A frame, with a controlled
   `0.20–0.50 m`, `10–25°` view perturbation and audited online-A co-visibility.
4. Require the factual online-B switch endpoint to have Goal-C co-visibility
   at most `0.10`.
5. Before C, reset NavDP's short FIFO and freeze long-memory retrieval at the
   end of A.  Earlier B frames are reported descriptively but cannot retrieve
   Goal-C.  The certified graph arm may use the causally traversed B→A history
   arc only after Goal-C is independently certified and physical stagnation is
   detected.
6. Construction is completed and SHA-sealed before any C arm runs.  An episode
   can be excluded only by the frozen constructibility contract; integrity,
   hash, source-role, or replay errors abort rather than shrink the denominator.

The primary endpoint is `SR_C | frozen online A success, online B success`.
This isolates Revisit-C capability; A/B are byte-identical factual prefixes,
not newly sampled policy outcomes.

## Paired arms

Every constructible episode runs all five arms in cyclically balanced order on
one persistent GPU/server pair:

| arm | C controller | role knowledge | purpose |
|---|---|---|---|
| `native` | frozen ImageGoal NavDP | none | no-memory baseline |
| `known_direct` | raw-DINO anchor → LingBot PointGoal | told C is Revisit | old upper comparator |
| `certified` | DINO top-8 → LightGlue/Fundamental → LingBot-depth PnP certificate → scale-free bearing | none | role-free direct method |
| `certified_budget` | same certified bearing; one stuck-budget reset | none | equal-budget causal control |
| `certified_graph` | same certified bearing; after the same stuck event follow the causal history arc | none | latest topology-aware method |

All arms use the same 600-step C budget, execution horizon 8, deterministic
per-plan diffusion seeds, frozen NavDP/LingBot/checkpoints, no Habitat pose or
geodesic in policy decisions, no candidate resampling, no terminal U-turn, and
no CDEC learned rescue.

## Frozen comparisons and audits

- Main deployment comparison: `certified_graph - native`.
- Open-set localization comparison: `certified - native`.
- Role oracle diagnostic: `known_direct - native`.
- Topology causal contrast: `certified_graph - certified_budget`.

Every comparison reports N, successes, paired gains/losses, exact two-sided
McNemar p, and a scene-cluster bootstrap 95% interval.  The audit requires:

- identical A and B trace SHA256 values and exact replay records in all arms;
- identical certified physical, memory, and causal-plan prefixes through the
  treatment boundary;
- matched budget/graph intervention steps;
- no historical subgoal in the budget arm;
- at least one actually emitted historical subgoal for every graph gain;
- a sealed source bundle, dependency receipts, balanced arm-order receipt,
  and an independent raw-file recount.

## Interpretation boundary

This is an internal strict retest on already consumed source scenes.  It can
repair the causal interpretation of the 43.5% result and select the correct
architecture, but it is not scene-disjoint paper confirmation.  The final
constructible N may be below 22; that reduction is reported as benchmark
feasibility, never hidden or treated as a navigation failure.

## Frozen result

The sealed run completed on 2026-08-14. Of 22 source episodes, 19 were
constructible under the frozen actual-online contract across 8 scene clusters;
three were rejected before any C-arm rollout because no Goal-C satisfied the
distance/support/endpoint-negative construction constraints. All five arms
share byte-identical A/B prefixes, all treatment prefixes match through the
intervention boundary, and an independent raw-file recount reproduced every
success and paired contrast.

| arm | C successes | `SR_C | frozen online A,B` |
|---|---:|---:|
| native | 5/19 | 26.3% |
| known-role direct | 14/19 | 73.7% |
| role-free certified | **16/19** | **84.2%** |
| certified + equal stuck budget | 16/19 | 84.2% |
| certified + graph rescue | 16/19 | 84.2% |

Paired results:

- certified − native: `+11/−0`, risk difference `+57.9 pp`, exact McNemar
  `p=0.0009766`, scene-cluster bootstrap 95% CI `[+27.8,+85.7] pp`;
- known-role direct − native: `+10/−1`, `p=0.01172`;
- graph rescue − equal-budget certified: `+0/−0`, `p=1.0`.

Graph rescue actually intervened in 3 episodes and emitted 92 historical graph
plans, so the null contrast is not an inactivity artifact. The architecture
decision is therefore to retain the **minimal role-free certified residual**
and remove graph rescue from the main method. This is a strong internal paired
result, not a scene-disjoint paper confirmation.
