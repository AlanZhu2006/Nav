## 0. 一页结论

1. **方向是 Novel-A 的主要可恢复瓶颈**，已由 N=40 严格配对确立
   （28/40 → 40/40，+12/−0，exact McNemar p=4.9e-4）。这是全项目
   **最强的机制结果**，但干预用的 bearing 全部来自 Habitat oracle。
2. **可靠记忆几何仍是唯一显著且可部署的方法结果**
   （2-leg joint 4/40 → 19/40，p=6.1e-5，HPC）。它现在的正确定位是
   "revisit 场景下的一个方向来源"。
3. **learned 路由五次尝试全部未能在部署形态上超过 max-DINO**；根因已定位为
   概率尺度不跨场景迁移（可修，已修一半），而非特征不足。
4. **2026-08-09 的最新发现推翻了"换更强视觉匹配器"的路线**：CLS、RANSAC、
   dense patch 三个通道的 **episode 内判别力全部 ≤ 0.43**（n=21 对，
   无法与 0.5 区分）。同场景 alias 面前，现有全部**外观类**证据失效。
5. **项目的唯一 open problem** 收敛为：为 novel 目标找到可部署的方向源。
   当前冻结的最小检验不是再做单帧 bearing 分类，而是 Cyclic Goal Compass：
   以主动 8-yaw 单目环视把欠定的全局猜方向改写成 C8 等变的 goal-conditioned
   局部进展场。
6. CGC 完整 smoke `15526905` 已 **COMPLETED 0:0**；正式 40-scene observability
   作业 `15527318` 已预约 2026-08-09 20:00 CST，8 小时为 wall-time 上限而非
   调参配额。它不读 development/blind，结果出来前没有方法增益声明。

#### X-NavDP 最新进展兼容性审计（2026-08-09）

对官方 commit `878740a…` 与 post-train checkpoint `267089a…` 做了 CPU
逐 tensor 审计：与原 NavDP 共享的 **1062 个 tensor 全部 exact equal**，包括
RGB-D encoder、ImageGoal/PointGoal encoder 与原 decoder；checkpoint 只新增
624 个 tensor（fine-tuned decoder、twin-Q、embodiment 等）。因此它适合做
**旁挂 PointGoal recovery branch**，不应冒充已 post-train 的 ImageGoal 模型；
官方 eval/observation 路径也只暴露 PointGoal。

在既有 9 个 consumed Novel-A plan-0 state（8 scene cluster）上，以同一 RGB-D、
同一 diffusion seed、8 个固定方向、每方向 8 候选做纯 PointGoal 执行审计：

- oracle-nearest request：X-NavDP post actor **7/9**，现役 mixed-token **8/9**
  （+1/−2，p=1.0），byte-identical base actor 的纯 PointGoal 为 **9/9**；
- post actor 相对 base actor 为 **+0/−2，p=0.5**，不支持全局替换执行器；
- 但它确实新增了恢复模态：`−180°` request fidelity 从 base actor **0/9 →
  9/9**，平均 extent 0.40→1.13 m；代价是 `−90°` 8/9→2/9、`+90°`
  7/9→2/9；
- X-NavDP Q 跨 request 命中 oracle 仅 4/9，且输入没有 ImageGoal，不能解释为
  goal-direction source。

这是 heading/extent 的小样本机制探针，不是安全、progress 或闭环结果；9 条的
oracle bearing 也没有后向案例。冻结决定：**保留现役 mixed-token 作为默认
执行器；X-NavDP 只保留为后向 recovery primitive 假设，若以后推进，必须先在
train-scene off-policy 状态做碰撞+短时 geodesic progress gate。** 它不改变
CDA O1/O2 的优先级，也没有解决 Novel ImageGoal 的方向来源。

## 3. leg-B 失败的真共视分解（2026-08-09 重写）

### 3.1 为何重写

旧分解用"记忆帧距 B ≤3.5 m 且朝向 B ±45°"作可见性代理。该代理与生成器
定义不符：goal 图在 B 处沿固定 yaw 拍摄，走到 B 跟前**回头看 B** 的帧与它
几乎无共同表面，而 goal 相机**后方数米、同向**的帧共视度很高。

重算改用生成器自身定义（`_goal_world_pts` 反投影 + `covis_frac`），在策略
leg-A 记忆轨迹的每个记录位姿处**重渲深度**，40 条 episode 全量计算。
结果：旧版的"floor 滤掉真匹配"整类**不存在**，是代理伪影。

### 3.2 修正后的分解（8 条 B 失败，covis≥0.5 为正例）

| 类 | n | 判据 | 修复层 |
|---|---:|---|---|
| A 目标从未被观测 | 1 | 全轨迹 max covis 0.47 | 不可修 |
| B 正例帧全在 anchor_margin 外 | 2 | 14–29 个正例帧，可达（≥frame 39）**0 个** | 记忆架构 |

## 4. 三通道判别力：分层后的关键否定结果

### 4.1 RANSAC 的 Simpson 悖论

汇总统计曾显示"通过 RANSAC 是不正确的弱证据"（LLR −0.47 nats）。**该结论
已撤回**——验证循环首个通过即停，成功 episode 平均贡献 1.3 个唯一 anchor
试验、失败 episode 贡献 2.5 个，汇总被失败层主导。

按 episode 结局分层：

| episode 结局 | anchor | n | RANSAC 通过率 |
|---|---|---:|---:|
| 成功 | 非正例 | 16 | **100.0%** |
| 成功 | 真正例 | 8 | 75.0% |
| 失败 | 非正例 | 13 | 23.1% |
| 失败 | 真正例 | 7 | **0.0%** |

层内显示：**RANSAC 判决几乎不携带 anchor 正确性信息，而由 episode 难度
主导**。作为门，其净效果是在最需要记忆的困难 episode 里关闭记忆。

### 4.2 patch 通道：pooled 好看、episode 内失效

在 44 个真实被验证过的 anchor（15 正例）上比较三通道：

| 通道 | pooled AUC | **episode 内 AUC** |
|---|---:|---:|
| CLS 余弦（现役检索分数） | 0.628 | **0.333** |
| RANSAC 通过（现役门） | 0.375 | **0.405** |
| patch: affine residual q90 | 0.777 | **0.429** |
| patch: mutual match fraction | 0.697 | **0.143** |
| patch: best match q90 | 0.575 | **0.048** |

**全部通道的 episode 内 AUC ≤ 0.43。** patch 的 pooled 优势完全来自
episode 之间的差异（困难 episode 整体残差大），一到 episode 内部即消失。

**统计边界**：episode 内正-负对仅 **21 对**，AUC 0.43 与 0.5 无法区分。
准确表述是"**没有证据表明任何通道在 episode 内有正向判别力**"，而非
"已证明它们都是负的"。

### 4.3 推论

问题不在"用 DINO 还是 patch 还是换 SALAD/LoFTR/MASt3R"，而在于：**同场景
alias 面前，现有全部外观类证据失效**。这些 SOTA 方法改进的仍是"两张图像
有多像 / 多好配准"，大概率逃不出同一陷阱。

能打破的只能是**非外观证据**：机器人自身位姿链、时序连续性、"候选位置与
一路走来的观测史是否相容"（carving）。这正是 GLP 相对纯匹配路线的卖点——
不问"哪个候选更像目标"，而问"哪个候选与我的观测史相容"。

## 5. learned 路由五次尝试的统一解释

| 尝试 | 结果 | 失败位置 |
|---|---|---|
| 旧 gate（flowgate/gatecurr） | gate acc 69→81%，top-1/action/pose 全没动 | 激活决策 |
| DINO-only set model | recall@1 67.65% < max-DINO 82.35% | 排序+激活 |
| Phase-B session 决策 | 校准后 84.5% < 87.3% | 激活决策 |
| hybrid P0（learned 重排叠在几何门后） | 结构上无决定权（floor→RANSAC→首个通过即停），8 条失败无一落在可作用区间 | 架构位置 |
| patch/temporal verifier | 离线 96.3% acc，**从未进闭环**；本文 §4.2 显示 episode 内无优势 | 从未部署 |

**统一解释**（泛化失败面各不相同）：

| 组件 | 泛化得好的 | 泛化不了的 | 证据 |
|---|---|---|---|
| DINO（冻结基础模型） | **分数尺度** | 实例级判别 | 阈值迁移损失仅 1.8 pp |
| SIFT/RANSAC（硬几何） | **精度**（20 场景 0 次误激活） | **召回**（随场景纹理剧变） | §4.1 |
| 小学习头 | **判别力**（候选级 AUC 每次赢） | **校准**（尺度在 40 场景上拟合） | 负样本均分 0.011→0.204 |

排序是相对判断（尺度消掉），激活是绝对判断（尺度漂移致命）。**五次都把
学习头放在它泛化失败面正好咬到的位置。**

## 6. 方法论教训（已付学费，应固化为规则）

1. **两次离线/轶事外推闭环翻车**：top-K 预测 "+3~5 条" → 实际 0；
   Stage 2 预测"只强不弱" → 未通过。
2. **两个不公平基线**：trainer 报告用固定 0.5 阈值把 DINO 压到 21.7%
   （换 train 调阈值后 87.3%）；in-sample 阈值把负样本压到 0.011。
3. **两次分层混淆**：RANSAC 的 Simpson 悖论；patch 的 pooled-vs-内部
   倒挂。**pooled 指标从此不作为通过条件。**
4. **一次代理错误**：可见性代理（距离+朝向）与真共视不符，导致整个分解
   需要重写。
5. **跨机器 CUDA 非确定性**：同 checkpoint 同策略，本地 Novel A 26/40 vs
   HPC 31/40 → 一切配对必须同机同进程。
6. **fail-closed 审计实际救过一次真数据错误**（dev 2 个正样本被标反），
   但也有两条检查从未真正执行过（overlay 未挂载、幽灵测试模块）。

**新增规则**：
- 任何增益报告必须附 **N、配对增减、显著性**；N<20 标为轶事级；
- 新通道必须先过 **episode 内判别**，pooled AUC 仅作筛子；
- 门槛从一开始就用**部署形态**（阈值只在 train 冻结、跨场景迁移后评估）。

## 7. 当前 open problems 与优先队列

### 7.1 唯一的核心 open problem

**为 novel 目标找到可部署的方向源。** 上限已知（oracle 40/40）、执行层
就绪（token 接口 + 死区刻画 + abstain 规则）、精度规格已知（±30° 系统偏差
仍全兑现，每 4 周期刷新足够，**但仅起点一次净负 +2/−3——方向必须是流**）。

已测五条路线：四条未通过（goal-blind frontier / DINO-CLS 排序 / NavDP
critic / 冻结 diffusion 的等权去噪误差差值）、一条被现成数据分布证伪
（直接 bearing 头）。简单 score-field 在 9-state probe 上仅 1/9 命中，oracle
request 平均排名 4.56（随机 4.5）。现在冻结的下一问是：**主动获得一个完整
SO(2) 观测轨道后，冻结 ImageGoal feature 是否含跨场景可读的目标进展信号**。
CGC 用随机 cyclic gauge、same-state goal swap、无 oracle candidate mask 和
scene-OOF 同时堵住“永远向前”、场景记忆、自由空间与几何泄漏 shortcut。

#### CGC 今晚任务的准确边界

- 数据：train-only 40 scenes，160 physical scans / 320 goal-conditioned rows /
  1280 单目 views；development、final-reserved、blind 均不进入代码路径；
- 教师：8 个 `try_step` transition 的 1 m geodesic progress；撞墙自然为零，
  沿墙滑动按实际终点计分，8/8 均由模型排序；
- 模型：冻结 NavDP ImageGoal encoder；先 shared linear，只有未通过才训练两层
  circular-conv ring head；5-fold scene OOF × 3 seeds，固定 300 epochs；
- gate：50% takeover budget 下净进展 scene-bootstrap lower95>0、实际接管率≥25%、
  same-state swapped-goal NLL increase lower95>0、primary teacher pair contrast≥25%；
- 通过只授权一个新预注册、场景不相交的 policy-state gate；不授权回看耗尽 dev
  调阈值，也不授权 blind 或论文效果声明。
